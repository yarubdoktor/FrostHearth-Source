# المرحلة 38 — توحيد مخطط ساحات المنافسة

## ما أُضيف
- عقد بيانات مشترك `competition_arena.gd` بنمطين: ميدان تأهل لأربع مدن، وخريطة مبنى الملك بسعة تصميمية تصل إلى 100 لاعب.
- ميدان التأهل يملك أربع نقاط ظهور وهدف سيطرة مركزي.
- خريطة مبنى الملك مقسمة إلى 25 قطاعاً (شبكة 5×5)، مع قطاع مركزي خاص بمبنى الملك.
- شاشة معاينة مستقلة تسمح بالتبديل بين المخططين، ومركز منافسة يفتحها.
- اختبار ثابت للعقد والحدود.

## قرار الحفاظ على الخريطة الأصلية
لم تُحذف ملفات الخريطة القديمة ولم تُعدّل آليات جمع الموارد أو بيانات الحفظ. أصول البيئة القديمة مسموح بإعادة استخدامها وفق العقد، لكن تحويل الأصول والمشهد ثلاثي الأبعاد نفسه مؤجل حتى تدقيق كل الاعتماديات. هذا يمنع كسر المدينة أو خريطة العالم الحالية قبل وجود بديل مُراجع.

## حدود هذه المرحلة
هذه معاينة تخطيطية محلية وليست مباراة قابلة للعب. لا يوجد قتال حقيقي، تحريك جيوش، مزامنة لاعبين، احتساب موسم، مكافآت، أو تحقق خادمي. سعة 100 لاعب حد تصميمي وليست اتصالاً متزامناً حقيقياً.

## الخطوة التالية
1. جرد اعتماديات خريطة العالم القديمة والمشاهد والموارد والضباب والكاميرا.
2. فصل بيانات العرض عن منطق المقاطعات وجمع الموارد دون حذف الملفات القديمة.
3. بناء مشهد ساحة ثلاثي الأبعاد قابل لإعادة الاستخدام مع إعدادات حجم ونقاط ظهور وأهداف مختلفة.
4. إضافة حركة وسيطرة محلية تجريبية واختبارات، ثم لاحقاً تصميم واجهة اتصال الخادم.
