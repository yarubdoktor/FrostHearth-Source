# المرحلة 40 — نموذج السيطرة على الأهداف

## ما أُضيف
- نموذج بيانات مستقل للسيطرة على أهداف المنافسة، متوافق مع عقد خريطة التأهل ومبنى الملك.
- تسجيل عدد الوحدات الموجودة لكل لاعب عند كل هدف.
- تقدم السيطرة، تثبيت السيطرة عند وجود دفاع، إيقاف التقدم عند التعادل، وإضعاف سيطرة المالك عند هجوم غير مدافع عنه.
- اختبار عقدي يغطي السيطرة، الدفاع، التعادل، هجوم الخصم، المدخلات غير الصالحة، وحدود خطوة المحاكاة.

## حدود المرحلة
- هذا محرك قواعد محلي تجريبي فقط؛ لا يوجد قتال فعلي أو تحريك جيوش أو اتصال خادم.
- النتائج غير موثوقة ولا تمنح نقاط موسم أو مكافآت، ولا تكتب إلى ملف الحفظ.
- يجب أن يكون الخادم المستقبلي هو المرجع النهائي للسيطرة والنتائج قبل فتح المنافسة الحقيقية.
- لم يتم استبدال خريطة العالم القديمة أو تعديل نظام المدينة والحفظ.
